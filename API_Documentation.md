# API Documentation

**Base URL:** `http://localhost:8080`

---

## Общие сведения

Все методы принимают параметры POST-запросов в формате `application/x-www-form-urlencoded`, GET-параметры — через query string.

Сессия ведётся через cookie `PHPSESSID`. После успешной регистрации или входа сервер устанавливает cookie, которую необходимо передавать в последующих запросах.

Время жизни сессии — 30 дней с момента последнего запроса: каждый метод, требующий авторизации, продлевает сессию и переотправляет cookie с новым сроком действия. Клиент должен сохранять обновлённую cookie из ответа.

### Формат ответа

Успешный ответ:
```json
{ "status": 1, "response": { ... } }
```

Ответ с ошибкой:
```json
{ "status": 0, "errorCode": <int> }
```

При внутренней ошибке сервера ответ приходит с HTTP-статусом 500 и `errorCode` 9001.

### Объект User

| Поле      | Тип           | Описание                                              |
|-----------|---------------|-------------------------------------------------------|
| `userId` | Int           | Идентификатор пользователя                            |
| `login`   | String        | Логин                                                 |
| `name`    | String        | Отображаемое имя                                      |
| `avatar`  | File \| null  | Аватар — объект [File](#объект-file) типа `image` (опционально) |

```json
{
  "userId": 1,
  "login": "ivan",
  "name": "Ivan Petrov",
  "avatar": {
    "fileId": 1,
    "type": "image",
    "url": "http://localhost:8080/static/uploads/2026/09/952c7adde9fc838c66ee905324c1e8fa.jpg",
    "size": 8293,
    "filename": "avatar.jpg",
    "extension": "jpg",
    "data": {
      "smallUrl": "http://localhost:8080/static/uploads/2026/09/952c7adde9fc838c66ee905324c1e8fa_small.jpg"
    }
  }
}
```

### Объект File

| Поле        | Тип    | Описание                                                        |
|-------------|--------|-----------------------------------------------------------------|
| `fileId`   | Int    | Идентификатор файла                                             |
| `type`      | String | Тип файла: `image` или `other` (список будет расширяться)        |
| `url`       | String | Ссылка на файл                                                  |
| `size`      | Int    | Размер в байтах                                                 |
| `filename`  | String | Имя файла                                                       |
| `extension` | String | Расширение файла; если расширения нет — `"file"`                |
| `data`      | Object | Дополнительная информация, состав зависит от `type` (см. ниже)   |

`data` для `other` — пустой объект `{}`.

`data` для `image`:

| Поле        | Тип    | Описание                                                                        |
|-------------|--------|---------------------------------------------------------------------------------|
| `smallUrl` | String | Ссылка на уменьшенную копию: не более 200 пикселей по меньшей стороне           |

```json
{
  "fileId": 1,
  "type": "image",
  "url": "http://localhost:8080/static/uploads/2026/09/952c7adde9fc838c66ee905324c1e8fa.jpg",
  "size": 8293,
  "filename": "photo.jpg",
  "extension": "jpg",
  "data": {
    "smallUrl": "http://localhost:8080/static/uploads/2026/09/952c7adde9fc838c66ee905324c1e8fa_small.jpg"
  }
}
```

### Объект Conversation

| Поле             | Тип          | Описание                                                                 |
|------------------|--------------|--------------------------------------------------------------------------|
| `conversationId` | Int          | Идентификатор переписки                                                  |
| `type`           | String       | Тип переписки: `single` (личная) или `group` (групповая)                 |
| `memberIds`      | Int[]        | Идентификаторы пользователей, состоящих в переписке (по возрастанию)     |
| `name`           | String \| null | Название — только для `group`; для `single` всегда `null`             |
| `avatar`         | File \| null   | Аватар — объект [File](#объект-file) типа `image`; только для `group`, опционально; для `single` всегда `null` |
| `opponentUser`   | User \| null   | Собеседник — объект [User](#объект-user); только для `single` (второй участник относительно текущего пользователя); для `group` всегда `null` |

```json
{
  "conversationId": 1,
  "type": "single",
  "memberIds": [1, 2],
  "name": null,
  "avatar": null,
  "opponentUser": {
    "userId": 2,
    "login": "petr",
    "name": "Petr Sidorov",
    "avatar": null
  }
}
```

### Объект Message

| Поле             | Тип    | Описание                                                              |
|------------------|--------|-----------------------------------------------------------------------|
| `messageId`      | Int    | Идентификатор сообщения                                               |
| `conversationId` | Int    | Идентификатор переписки                                               |
| `blockId`        | Int    | Идентификатор блока, в котором лежит сообщение (см. [блоки сообщений](#блоки-сообщений)) |
| `senderId`       | Int    | Идентификатор пользователя, отправившего сообщение                    |
| `type`           | String | Тип сообщения: пока только `text`                                      |
| `text`           | String | Текст сообщения                                                       |
| `isEdited`       | Bool   | Было ли сообщение отредактировано                                     |
| `createdAt`      | Int    | Время создания — Unix timestamp в секундах                            |
| `updatedAt`      | Int    | Время последнего изменения — Unix timestamp в секундах; у неотредактированного сообщения равно `createdAt` |

```json
{
  "messageId": 15,
  "conversationId": 1,
  "blockId": 2,
  "senderId": 1,
  "type": "text",
  "text": "Привет!",
  "isEdited": false,
  "createdAt": 1790846400,
  "updatedAt": 1790846400
}
```

### Блоки сообщений

Сообщения переписки хранятся блоками по 20 штук в порядке отправки: новое сообщение попадает в последний блок переписки, а если он заполнен — в новый. Идентификаторы блоков одной переписки возрастают от старых к новым. Блоки не пустые; заполненным может быть не только последний блок.

### Коды ошибок

| Код  | Описание                                              | Методы                        |
|------|-------------------------------------------------------|-------------------------------|
| 1001 | Невалидный `login` (в т. ч. длиннее 64 символов)      | `/auth/signup`, `/auth/login` |
| 1002 | Пароль не соответствует требованиям                   | `/auth/signup`, `/auth/login` |
| 1003 | Невалидное `name` (в т. ч. длиннее 128 символов)      | `/auth/signup`                |
| 1004 | Невалидные параметры запроса                          | `/users/getList`, `/conversations/getList` |
| 1005 | Невалидный текст сообщения: пустой (после обрезки пробелов) или длиннее 4096 символов | `/messages/send`, `/messages/edit` |
| 2001 | Логин уже занят                                       | `/auth/signup`                |
| 2002 | Неверный логин или пароль                             | `/auth/login`                 |
| 2003 | Пользователь не авторизован                           | `/auth/logout`, `/profile/get`, `/profile/setAvatar`, `/profile/removeAvatar`, `/files/uploadImage`, `/users/getList`, `/conversations/createSingle`, `/conversations/getList`, `/messages/getList`, `/messages/getBlock`, `/messages/send`, `/messages/edit` |
| 3001 | Файл не передан                                       | `/files/uploadImage`          |
| 3002 | Файл слишком большой (максимум 10 МБ или 25 мегапикселей) | `/files/uploadImage`      |
| 3003 | Файл не является изображением                         | `/files/uploadImage`, `/profile/setAvatar` |
| 3004 | Файл не найден / невалидный `fileId`                 | `/files/get`, `/profile/setAvatar` |
| 3005 | Ошибка сохранения файла                               | `/files/uploadImage`          |
| 4001 | Пользователь не найден / невалидный `userId`          | `/conversations/createSingle` |
| 5001 | Нельзя создать личную переписку с самим собой         | `/conversations/createSingle` |
| 5002 | Переписка не найдена, невалидный `conversationId` или пользователь в ней не состоит | `/messages/getList`, `/messages/send` |
| 6001 | Сообщение не найдено, невалидный `messageId` или сообщение из переписки, в которой пользователь не состоит | `/messages/edit` |
| 6002 | Блок сообщений не найден, невалидный `blockId` или блок из другой переписки | `/messages/getList`, `/messages/getBlock` |
| 6003 | Нельзя редактировать чужое сообщение                  | `/messages/edit`              |
| 9001 | Внутренняя ошибка сервера                             | Все методы                    |

## Методы

### POST /auth/signup — Регистрация

Создаёт нового пользователя и устанавливает сессию.

#### Параметры запроса

| Поле       | Тип    | Обязательное | Требования                                                                                         |
|------------|--------|--------------|----------------------------------------------------------------------------------------------------|
| `login`    | String | Да           | Латинские буквы (a–z, A–Z), цифры, символ `_`; не длиннее 64 символов                             |
| `password` | String | Да           | Не менее 8 символов; минимум одна заглавная буква (A–Z), одна строчная (a–z), одна цифра (0–9)    |
| `name`     | String | Да           | Буквы (любые), цифры, дефис `-`, нижнее подчёркивание `_`, пробел; не длиннее 128 символов        |

#### Успешный ответ

В `response` — объект [User](#объект-user) созданного пользователя.

```json
{
  "status": 1,
  "response": {
    "userId": 1,
    "login": "ivan",
    "name": "Ivan Petrov",
    "avatar": null
  }
}
```

### POST /files/uploadImage — Загрузка изображения

Загружает изображение и создаёт для него уменьшенную копию. Требует активной сессии. Тело запроса — `multipart/form-data`.

Через этот метод можно загрузить только изображения: JPEG, PNG, WebP. GIF изображением не считается (для него будет отдельный тип). Максимальный размер — 10 МБ и 25 мегапикселей (ширина × высота). Уменьшенная копия JPEG поворачивается согласно EXIF Orientation.

#### Параметры запроса

| Поле       | Тип    | Обязательное | Описание                                                                 |
|------------|--------|--------------|--------------------------------------------------------------------------|
| `file`     | File   | Да           | Сам файл                                                                 |
| `filename` | String | Нет          | Имя файла; если не указано — используется оригинальное имя загруженного файла. Обрезается до 255 символов, невалидные UTF-8 байты заменяются; `extension` обрезается до 32 символов |

#### Успешный ответ

В `response` — объект [File](#объект-file) с `type: "image"`.

```json
{
  "status": 1,
  "response": {
    "fileId": 1,
    "type": "image",
    "url": "http://localhost:8080/static/uploads/2026/09/952c7adde9fc838c66ee905324c1e8fa.jpg",
    "size": 8293,
    "filename": "photo.jpg",
    "extension": "jpg",
    "data": {
      "smallUrl": "http://localhost:8080/static/uploads/2026/09/952c7adde9fc838c66ee905324c1e8fa_small.jpg"
    }
  }
}
```

#### Ошибки

| Код  | Описание                          |
|------|-----------------------------------|
| 2003 | Пользователь не авторизован       |
| 3001 | Файл не передан                   |
| 3002 | Файл слишком большой (больше 10 МБ или 25 мегапикселей) |
| 3003 | Файл не является изображением     |
| 3005 | Ошибка сохранения файла           |

### GET /users/getList — Список пользователей

Возвращает пользователей по возрастанию `userId` с фильтром по подстроке и постраничной выдачей. Требует активной сессии.

Для получения следующей страницы передайте в `maxId` значение `nextMaxId` из предыдущего ответа; запрашивать дальше имеет смысл, пока `hasNext` равен `true`.

#### Параметры запроса

| Поле    | Тип    | Обязательное | Описание                                                                                   |
|---------|--------|--------------|--------------------------------------------------------------------------------------------|
| `query` | String | Нет          | Текст для фильтра: ищется как подстрока в `name` или `login` (без учёта регистра)           |
| `maxId` | Int    | Нет          | Отдавать только пользователей с `userId` больше указанного                                 |
| `count` | Int    | Нет          | Максимальное количество пользователей в выдаче; по умолчанию 30, максимум 100 (большие значения урезаются до 100) |

#### Успешный ответ

| Поле        | Тип          | Описание                                                                    |
|-------------|--------------|-----------------------------------------------------------------------------|
| `users`     | User[]       | Список объектов [User](#объект-user)                                        |
| `nextMaxId` | Int \| null  | `userId` последнего (максимального) пользователя в списке; `null`, если список пуст |
| `hasNext`   | Bool         | Есть ли ещё пользователи после этой страницы                                |

```json
{
  "status": 1,
  "response": {
    "users": [
      {
        "userId": 1,
        "login": "ivan",
        "name": "Ivan Petrov",
        "avatar": null
      },
      {
        "userId": 5,
        "login": "ivanova",
        "name": "Anna Ivanova",
        "avatar": null
      }
    ],
    "nextMaxId": 5,
    "hasNext": false
  }
}
```

#### Ошибки

| Код  | Описание                                                 |
|------|----------------------------------------------------------|
| 1004 | `maxId` или `count` не являются целым числом (`count` должен быть больше 0), или параметр передан массивом |
| 2003 | Пользователь не авторизован                              |

### POST /conversations/createSingle — Создание личной переписки

Создаёт личную переписку (`type: "single"`) между текущим пользователем и указанным. Если такая переписка уже существует — возвращает её без ошибки. Требует активной сессии.

#### Параметры запроса

| Поле     | Тип | Обязательное | Описание                                          |
|----------|-----|--------------|---------------------------------------------------|
| `userId` | Int | Да           | Идентификатор пользователя, с которым создаётся переписка |

#### Успешный ответ

| Поле           | Тип          | Описание                                                        |
|----------------|--------------|-----------------------------------------------------------------|
| `conversation` | Conversation | Объект [Conversation](#объект-conversation) созданной или уже существующей переписки |

```json
{
  "status": 1,
  "response": {
    "conversation": {
      "conversationId": 1,
      "type": "single",
      "memberIds": [1, 2],
      "name": null,
      "avatar": null,
      "opponentUser": {
        "userId": 2,
        "login": "petr",
        "name": "Petr Sidorov",
        "avatar": null
      }
    }
  }
}
```

#### Ошибки

| Код  | Описание                                       |
|------|------------------------------------------------|
| 2003 | Пользователь не авторизован                    |
| 4001 | Пользователь не найден / невалидный `userId`   |
| 5001 | `userId` совпадает с текущим пользователем     |

### GET /conversations/getList — Список переписок

Возвращает переписки, в которых состоит текущий пользователь, — сначала самые новые (по убыванию `conversationId`). Требует активной сессии.

Для получения следующей страницы увеличьте `offset` на количество уже полученных переписок; запрашивать дальше имеет смысл, пока `hasNext` равен `true`.

#### Параметры запроса

| Поле     | Тип | Обязательное | Описание                                                                                   |
|----------|-----|--------------|--------------------------------------------------------------------------------------------|
| `offset` | Int | Нет          | Сколько первых переписок пропустить; по умолчанию 0                                         |
| `count`  | Int | Нет          | Максимальное количество переписок в выдаче; по умолчанию 30, максимум 100 (большие значения урезаются до 100) |

#### Успешный ответ

| Поле            | Тип            | Описание                                                        |
|-----------------|----------------|-----------------------------------------------------------------|
| `conversations` | Conversation[] | Список объектов [Conversation](#объект-conversation)            |
| `hasNext`       | Bool           | Есть ли ещё переписки после этой страницы                       |

```json
{
  "status": 1,
  "response": {
    "conversations": [
      {
        "conversationId": 1,
        "type": "single",
        "memberIds": [1, 2],
        "name": null,
        "avatar": null,
        "opponentUser": {
          "userId": 2,
          "login": "petr",
          "name": "Petr Sidorov",
          "avatar": null
        }
      }
    ],
    "hasNext": false
  }
}
```

#### Ошибки

| Код  | Описание                                                                      |
|------|-------------------------------------------------------------------------------|
| 1004 | `offset` или `count` не являются целым числом (`count` должен быть больше 0)  |
| 2003 | Пользователь не авторизован                                                   |

### GET /messages/getList — Сообщения переписки

Возвращает сообщения переписки целыми [блоками](#блоки-сообщений) — от самых новых к старым: блоки добавляются в выдачу, пока сообщений не наберётся хотя бы 40 (или пока блоки не кончатся). Поэтому сообщений может быть больше 40. Требует активной сессии; пользователь должен состоять в переписке.

Сообщения в `messages` отсортированы от новых к старым (по убыванию `messageId`). Для загрузки более старых сообщений передайте в `blockId` значение `nextBlockId` из предыдущего ответа; запрашивать дальше имеет смысл, пока `hasNext` равен `true`.

#### Параметры запроса

| Поле             | Тип | Обязательное | Описание                                                                               |
|------------------|-----|--------------|----------------------------------------------------------------------------------------|
| `conversationId` | Int | Да           | Идентификатор переписки                                                                |
| `blockId`        | Int | Нет          | С какого блока начинать (он сам входит в выдачу, дальше идут более старые). Если не указан — с самого нового блока |

#### Успешный ответ

| Поле          | Тип         | Описание                                                                   |
|---------------|-------------|----------------------------------------------------------------------------|
| `messages`    | Message[]   | Список объектов [Message](#объект-message), от новых к старым              |
| `nextBlockId` | Int \| null | Идентификатор следующего (более старого) блока для загрузки; `null`, если его нет |
| `hasNext`     | Bool        | Есть ли ещё более старые сообщения                                         |

```json
{
  "status": 1,
  "response": {
    "messages": [
      {
        "messageId": 15,
        "conversationId": 1,
        "blockId": 2,
        "senderId": 1,
        "type": "text",
        "text": "Привет!",
        "isEdited": false,
        "createdAt": 1790846400,
        "updatedAt": 1790846400
      }
    ],
    "nextBlockId": 1,
    "hasNext": true
  }
}
```

#### Ошибки

| Код  | Описание                                                                            |
|------|-------------------------------------------------------------------------------------|
| 2003 | Пользователь не авторизован                                                         |
| 5002 | Переписка не найдена, невалидный `conversationId` или пользователь в ней не состоит |
| 6002 | Блок не найден, невалидный `blockId` или блок относится к другой переписке           |

### POST /messages/send — Отправка сообщения

Отправляет текстовое сообщение в переписку от лица текущего пользователя. Требует активной сессии; пользователь должен состоять в переписке.

#### Параметры запроса

| Поле             | Тип    | Обязательное | Описание                                                                         |
|------------------|--------|--------------|----------------------------------------------------------------------------------|
| `conversationId` | Int    | Да           | Идентификатор переписки                                                          |
| `text`           | String | Да           | Текст сообщения. Пробелы по краям обрезаются; после обрезки — от 1 до 4096 символов. Невалидные UTF-8 байты заменяются |

#### Успешный ответ

| Поле      | Тип     | Описание                                               |
|-----------|---------|--------------------------------------------------------|
| `message` | Message | Объект [Message](#объект-message) отправленного сообщения |

```json
{
  "status": 1,
  "response": {
    "message": {
      "messageId": 15,
      "conversationId": 1,
      "blockId": 2,
      "senderId": 1,
      "type": "text",
      "text": "Привет!",
      "isEdited": false,
      "createdAt": 1790846400,
      "updatedAt": 1790846400
    }
  }
}
```

#### Ошибки

| Код  | Описание                                                                            |
|------|-------------------------------------------------------------------------------------|
| 1005 | Текст пустой или длиннее 4096 символов                                              |
| 2003 | Пользователь не авторизован                                                         |
| 5002 | Переписка не найдена, невалидный `conversationId` или пользователь в ней не состоит |

### POST /messages/edit — Редактирование сообщения

Меняет текст сообщения и помечает его отредактированным (`isEdited: true`, `updatedAt` — время правки). Требует активной сессии. Редактировать можно только свои сообщения.

#### Параметры запроса

| Поле        | Тип    | Обязательное | Описание                                                       |
|-------------|--------|--------------|----------------------------------------------------------------|
| `messageId` | Int    | Да           | Идентификатор сообщения                                        |
| `newText`   | String | Да           | Новый текст; требования те же, что к `text` в `/messages/send` |

#### Успешный ответ

| Поле      | Тип     | Описание                                                 |
|-----------|---------|----------------------------------------------------------|
| `message` | Message | Обновлённый объект [Message](#объект-message)            |

```json
{
  "status": 1,
  "response": {
    "message": {
      "messageId": 15,
      "conversationId": 1,
      "blockId": 2,
      "senderId": 1,
      "type": "text",
      "text": "Привет! Как дела?",
      "isEdited": true,
      "createdAt": 1790846400,
      "updatedAt": 1790846520
    }
  }
}
```

#### Ошибки

| Код  | Описание                                                                                     |
|------|----------------------------------------------------------------------------------------------|
| 1005 | Текст пустой или длиннее 4096 символов                                                       |
| 2003 | Пользователь не авторизован                                                                  |
| 6001 | Сообщение не найдено, невалидный `messageId` или пользователь не состоит в переписке сообщения |
| 6003 | Сообщение отправлено другим пользователем                                                    |
