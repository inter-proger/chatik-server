# WebSocket: `events` — Служебные события протокола

[← WebSocket](../WebSocket.md) · [Документация API](../../../API_Documentation.md)

## `events` / `received` — подтверждение получения события

Клиент → сервер. Отправляется на каждое событие сервера, кроме группы `auth` (см. [Подтверждение получения](../WebSocket.md#подтверждение-получения)). До `auth` / `connected` — ошибка протокола (`4000`), как и любое сообщение кроме `auth` / `connect`.

| Поле `body`   | Тип    | Описание                           |
|---------------|--------|------------------------------------|
| `receivedUid` | String | `uid` полученного события сервера  |

```json
{
  "uid": "c3e1a7b2-5d4f-4a8e-9b6c-1f2e3d4c5b6a",
  "group": "events",
  "event": "received",
  "body": { "receivedUid": "7d2b9e4f-1a3c-4e5d-8f6a-2b4c6d8e0a1b" }
}
```

Сервер не отвечает на подтверждение. Подтверждение с неизвестным или чужим `receivedUid` сервер игнорирует.
