# Админ-панель

[← Документация API](../../API_Documentation.md)

Страница `GET /admin` — веб-интерфейс для отправки сообщений от имени выбранного пользователя: поиск пользователя по имени или логину, выбор его диалога, ввод текста. Страница работает через методы ниже; клиентским приложениям они не нужны.

Доступ — по логину и паролю админа (пока захардкожены в `core/Admin.php`: `admin` / `admin`). Сессия админа ведётся через отдельную cookie `ADMINSESSID` и не связана с сессией пользователя (`PHPSESSID`): вход в админку не даёт доступа к пользовательским методам, и наоборот. Время жизни — как у пользовательской сессии.

Формат ответа и коды ошибок — общие (см. [Формат ответа](General.md#формат-ответа), [Коды ошибок](Errors.md)). Все методы, кроме `/admin/login`, без входа отвечают ошибкой 2003. Actions методы админки не отдают.

## POST /admin/login — Вход админа

| Поле       | Тип    | Обязательное | Описание     |
|------------|--------|--------------|--------------|
| `login`    | String | Да           | Логин админа |
| `password` | String | Да           | Пароль админа |

Успешный ответ — пустой `response`, устанавливается cookie `ADMINSESSID`. Ошибки: 2002 — неверный логин или пароль.

## POST /admin/logout — Выход админа

Завершает сессию админа. Успешный ответ — пустой `response`. Ошибки: 2003.

## GET /admin/getUsers — Поиск пользователей

| Поле    | Тип    | Обязательное | Описание                                                        |
|---------|--------|--------------|-----------------------------------------------------------------|
| `query` | String | Нет          | Подстрока для поиска по `name` или `login`; пусто — все пользователи |

| Поле ответа | Тип    | Описание                                                       |
|-------------|--------|----------------------------------------------------------------|
| `users`     | User[] | До 50 объектов [User](Objects.md#объект-user) по возрастанию `userId`    |
| `hasNext`   | Bool   | Совпадений больше 50 — нужно уточнить запрос                   |

Ошибки: 1004 — `query` не строка, 2003.

## GET /admin/getConversations — Переписки пользователя

| Поле     | Тип | Обязательное | Описание                                      |
|----------|-----|--------------|-----------------------------------------------|
| `userId` | Int | Да           | Пользователь, чьи переписки нужны             |
| `offset` | Int | Нет          | Сколько переписок пропустить (по умолчанию 0) |
| `count`  | Int | Нет          | Сколько вернуть: по умолчанию 30, максимум 100 |

| Поле ответа     | Тип            | Описание                                                                 |
|-----------------|----------------|--------------------------------------------------------------------------|
| `conversations` | Conversation[] | Объекты [Conversation](Objects.md#объект-conversation) глазами пользователя `userId` (`opponentUserId` — его собеседник), сначала новые |
| `users`         | User[]         | Объекты [User](Objects.md#объект-user) всех участников переписок в выдаче, по возрастанию `userId` |
| `hasNext`       | Bool           | Есть ли следующая страница                                               |

Ошибки: 1004 — невалидные `offset` / `count`, 2003, 4001 — пользователь не найден или невалидный `userId`.

## POST /admin/sendMessage — Отправка сообщения от имени пользователя

Отправляет сообщение так же, как [`/messages/send`](methods/Messages.md#post-messagessend--отправка-сообщения), но от имени пользователя `userId`; `clientId` не передаётся — сервер генерирует UUID. Участникам переписки, включая самого отправителя, рассылается WebSocket-событие [`messages` / `received`](websocket/Messages.md#messages--received--новое-сообщение).

| Поле             | Тип    | Обязательное | Описание                                                 |
|------------------|--------|--------------|----------------------------------------------------------|
| `userId`         | Int    | Да           | Отправитель                                              |
| `conversationId` | Int    | Да           | Переписка, в которой состоит отправитель                 |
| `text`           | String | Да           | Текст; требования те же, что в `/messages/send`          |

| Поле ответа | Тип     | Описание                                                  |
|-------------|---------|-----------------------------------------------------------|
| `message`   | Message | Объект [Message](Objects.md#объект-message) отправленного сообщения |

Ошибки: 1005 — невалидный текст, 2003, 4001 — пользователь не найден или невалидный `userId`, 5002 — переписка не найдена, невалидный `conversationId` или пользователь в ней не состоит.
