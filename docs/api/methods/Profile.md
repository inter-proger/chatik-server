# /profile — Профиль текущего пользователя

[← Методы API](../Methods.md) · [Документация API](../../../API_Documentation.md)

## GET /profile/get — Профиль текущего пользователя

Возвращает объект [User](../Objects.md#объект-user) для авторизованного пользователя. Требует активной сессии.

### Параметры запроса

Отсутствуют.

### Успешный ответ

```json
{
  "status": 1,
  "response": {
    "userId": 1,
    "login": "ivan",
    "name": "Ivan Petrov",
    "avatar": null
  }
}
```

### Ошибки

| Код  | Описание                    |
|------|-----------------------------|
| 2003 | Пользователь не авторизован |

---

## POST /profile/setAvatar — Установка аватара

Устанавливает аватар текущего пользователя. Требует активной сессии. Файл должен быть загружен этим же пользователем через `/files/uploadImage` и иметь тип `image`.

### Параметры запроса

| Поле      | Тип | Обязательное | Описание                                   |
|-----------|-----|--------------|--------------------------------------------|
| `fileId` | Int | Да           | Идентификатор ранее загруженного изображения |

### Успешный ответ

В `response` — обновлённый объект [User](../Objects.md#объект-user).

```json
{
  "status": 1,
  "response": {
    "userId": 1,
    "login": "ivan",
    "name": "Ivan Petrov",
    "avatar": {
      "fileId": 1,
      "type": "image",
      "url": "http://localhost:8080/static/uploads/2026/09/952c7adde9fc838c66ee905324c1e8fa.jpg",
      "size": 8293,
      "filename": "avatar.jpg",
      "extension": "jpg",
      "data": {
        "smallUrl": "http://localhost:8080/static/uploads/2026/09/952c7adde9fc838c66ee905324c1e8fa_small.jpg"
      }
    }
  }
}
```

### Ошибки

| Код  | Описание                                                        |
|------|-----------------------------------------------------------------|
| 2003 | Пользователь не авторизован                                     |
| 3003 | Файл не является изображением                                   |
| 3004 | Файл не найден, невалидный `fileId` или файл принадлежит другому пользователю |

---

## POST /profile/removeAvatar — Удаление аватара

Убирает аватар текущего пользователя. Требует активной сессии. Сам файл не удаляется. Если аватар не был установлен — метод всё равно завершается успешно.

### Параметры запроса

Отсутствуют.

### Успешный ответ

В `response` — обновлённый объект [User](../Objects.md#объект-user) с `avatar: null`.

```json
{
  "status": 1,
  "response": {
    "userId": 1,
    "login": "ivan",
    "name": "Ivan Petrov",
    "avatar": null
  }
}
```

### Ошибки

| Код  | Описание                    |
|------|-----------------------------|
| 2003 | Пользователь не авторизован |
