# /global — Старт приложения и WebSocket-токен

[← Методы API](../Methods.md) · [Документация API](../../../API_Documentation.md)

## GET /global/start — Старт работы приложения

Возвращает данные, нужные клиенту для начала работы. Клиент вызывает метод:

- при запуске приложения;
- после входа, регистрации и выхода;
- при возврате приложения из фона.

Для переподключений к WebSocket используется лёгкий метод [`/global/getWebsocketToken`](#get-globalgetwebsockettoken--токен-подключения-к-websocket) — `/global/start` для этого не вызывается.

Метод доступен без авторизации. Для авторизованного пользователя продлевает сессию, как и остальные методы. Ответ отдаётся с заголовком `Cache-Control: no-store` (содержит токен). Состав ответа в дальнейшем будет расширяться — клиент должен игнорировать неизвестные поля.

### Параметры запроса

Отсутствуют.

### Успешный ответ

| Поле                    | Тип                           | Описание                                                                 |
|-------------------------|-------------------------------|--------------------------------------------------------------------------|
| `websocketConnectInfo`  | WebsocketConnectInfo \| null  | Объект [WebsocketConnectInfo](../Objects.md#объект-websocketconnectinfo); `null`, если пользователь не авторизован |

Авторизованный пользователь:
```json
{
  "status": 1,
  "response": {
    "websocketConnectInfo": {
      "url": "wss://example.com/ws",
      "token": "3f9c1e0b8a7d4c2e9f6a5b4c3d2e1f0a3f9c1e0b8a7d4c2e9f6a5b4c3d2e1f0a",
      "expiresIn": 120
    }
  }
}
```

Неавторизованный пользователь:
```json
{
  "status": 1,
  "response": {
    "websocketConnectInfo": null
  }
}
```

### Ошибки

Специфичных ошибок нет: неавторизованный пользователь получает успешный ответ с `websocketConnectInfo: null`.

## GET /global/getWebsocketToken — Токен подключения к WebSocket

Выдаёт новый токен для (пере)подключения к [WebSocket](../WebSocket.md). Метод лёгкий — только выдаёт токен, и предназначен для частых вызовов при переподключениях. Требует активной сессии и продлевает её. Ответ отдаётся с заголовком `Cache-Control: no-store`.

### Параметры запроса

Отсутствуют.

### Успешный ответ

| Поле                   | Тип                  | Описание                                                       |
|------------------------|----------------------|----------------------------------------------------------------|
| `websocketConnectInfo` | WebsocketConnectInfo | Объект [WebsocketConnectInfo](../Objects.md#объект-websocketconnectinfo)     |

```json
{
  "status": 1,
  "response": {
    "websocketConnectInfo": {
      "url": "wss://example.com/ws",
      "token": "3f9c1e0b8a7d4c2e9f6a5b4c3d2e1f0a3f9c1e0b8a7d4c2e9f6a5b4c3d2e1f0a",
      "expiresIn": 120
    }
  }
}
```

### Ошибки

| Код  | Описание                                                                                     |
|------|----------------------------------------------------------------------------------------------|
| 2003 | Пользователь не авторизован — клиент переходит в неавторизованное состояние и не переподключается |

## GET /global/getTotalUnreadCount — Общий счётчик непрочитанных

Возвращает число непрочитанных сообщений текущего пользователя по всем перепискам — для фонового обновления бейджа. Требует активной сессии.

### Параметры запроса

Отсутствуют.

### Успешный ответ

| Поле               | Тип | Описание |
|--------------------|-----|----------|
| `totalUnreadCount` | Int | Непрочитанные по всем перепискам |
| `changeVersion`    | Int | Текущая [версия пользователя](../Objects.md#версия-пользователя), на которой снят счётчик |

```json
{
  "status": 1,
  "response": {
    "totalUnreadCount": 3,
    "changeVersion": 120
  }
}
```

Клиент применяет счётчик по правилам [ReadInfo](../Objects.md#объект-readinfo): если `changeVersion` больше локальной версии счётчика.

### Ошибки

| Код  | Описание |
|------|----------|
| 2003 | Пользователь не авторизован |
