# /users — Пользователи

[← Методы API](../Methods.md) · [Документация API](../../../API_Documentation.md)

## GET /users/getList — Список пользователей

Возвращает пользователей по возрастанию `userId` с фильтром по подстроке и постраничной выдачей. Требует активной сессии.

Для получения следующей страницы передайте в `maxId` значение `nextMaxId` из предыдущего ответа; запрашивать дальше имеет смысл, пока `hasNext` равен `true`.

### Параметры запроса

| Поле    | Тип    | Обязательное | Описание                                                                                   |
|---------|--------|--------------|--------------------------------------------------------------------------------------------|
| `query` | String | Нет          | Текст для фильтра: ищется как подстрока в `name` или `login` (без учёта регистра)           |
| `maxId` | Int    | Нет          | Отдавать только пользователей с `userId` больше указанного                                 |
| `count` | Int    | Нет          | Максимальное количество пользователей в выдаче; по умолчанию 30, максимум 100 (большие значения урезаются до 100) |

### Успешный ответ

| Поле        | Тип          | Описание                                                                    |
|-------------|--------------|-----------------------------------------------------------------------------|
| `users`     | User[]       | Список объектов [User](../Objects.md#объект-user)                                        |
| `nextMaxId` | Int \| null  | `userId` последнего (максимального) пользователя в списке; `null`, если список пуст |
| `hasNext`   | Bool         | Есть ли ещё пользователи после этой страницы                                |

```json
{
  "status": 1,
  "response": {
    "users": [
      {
        "userId": 1,
        "login": "ivan",
        "name": "Ivan Petrov",
        "avatar": null
      },
      {
        "userId": 5,
        "login": "ivanova",
        "name": "Anna Ivanova",
        "avatar": null
      }
    ],
    "nextMaxId": 5,
    "hasNext": false
  }
}
```

### Ошибки

| Код  | Описание                                                 |
|------|----------------------------------------------------------|
| 1004 | `maxId` или `count` не являются целым числом (`count` должен быть больше 0), или параметр передан массивом |
| 2003 | Пользователь не авторизован                              |

## GET /users/getBatch — Пользователи по списку id

Возвращает пользователей по списку идентификаторов — например, для обновления локального кэша по [action `users`](../General.md#action-users). Требует активной сессии.

### Параметры запроса

| Поле      | Тип   | Обязательное | Описание                                                                                   |
|-----------|-------|--------------|--------------------------------------------------------------------------------------------|
| `userIds` | Int[] | Да           | Идентификаторы пользователей, от 1 до 100 штук. Передаются через запятую (`userIds=1,2,3`) или массивом (`userIds[]=1&userIds[]=2`). Повторы игнорируются |

### Успешный ответ

| Поле          | Тип    | Описание                                                                     |
|---------------|--------|------------------------------------------------------------------------------|
| `users`       | User[] | Объекты [User](../Objects.md#объект-user) найденных пользователей — в порядке `userIds`   |
| `notFoundIds` | Int[]  | Идентификаторы, для которых пользователь не найден, — в порядке `userIds`     |

```json
{
  "status": 1,
  "response": {
    "users": [
      {
        "userId": 2,
        "login": "petr",
        "name": "Petr Sidorov",
        "avatar": null
      },
      {
        "userId": 1,
        "login": "ivan",
        "name": "Ivan Petrov",
        "avatar": null
      }
    ],
    "notFoundIds": [999]
  }
}
```

### Ошибки

| Код  | Описание                                                                                     |
|------|----------------------------------------------------------------------------------------------|
| 1004 | `userIds` не передан, пуст, содержит больше 100 элементов или элемент, не являющийся целым неотрицательным числом |
| 2003 | Пользователь не авторизован                                                                  |
