# /groups — Групповые переписки

[← Методы API](../Methods.md) · [Документация API](../README.md)

Группа — переписка `type: "group"` (объект [Conversation](../Objects.md#объект-conversation)) с названием, необязательными описанием и аватаром. До 100 участников, включая владельца. Создатель становится **владельцем**; владелец ровно один и может всё: добавлять и удалять участников, передавать владение. Остальные участники читают и пишут сообщения и могут выйти. Вся история группы видна любому участнику, в том числе сообщения до его вступления; сообщения удалённых и вышедших остаются в группе.

Состав и роли — объект [GroupInfo](../Objects.md#объект-groupinfo), в Conversation группы `memberIds` равен `null`. Сообщения, прочтение и список переписок работают с группами так же, как с личными переписками.

Общие правила методов:

- Требуют активной сессии (`2003`).
- `5002` — группы нет, невалидный `conversationId` или текущий пользователь в ней не состоит: чужая группа неотличима от несуществующей. `5003` — переписка не группа. `5004` — действие доступно только владельцу.
- Изменение состава и владельца не меняет Conversation остальных участников: они получают событие с новой GroupInfo (см. [WebSocket: `groups`](../websocket/Groups.md)).

## POST /groups/create — Создание группы

Создаёт группу с текущим пользователем в роли владельца. Название, описание и аватар пока задаются только при создании.

### Параметры запроса

| Поле           | Тип    | Обязательное | Описание |
|----------------|--------|--------------|----------|
| `name`         | String | Да           | Название: после обрезки пробелов по краям — от 1 до 128 символов, любой текст (эмодзи, пунктуация) |
| `description`  | String | Нет          | Описание: после обрезки — до 1024 символов; пустое — описания нет (`null`) |
| `avatarFileId` | Int    | Нет          | Аватар — файл типа `image`, загруженный текущим пользователем методом [`/files/uploadImage`](Files.md#post-filesuploadimage--загрузка-изображения) |

### Успешный ответ

| Поле           | Тип          | Описание |
|----------------|--------------|----------|
| `conversation` | Conversation | Созданная группа — объект [Conversation](../Objects.md#объект-conversation) |
| `groupInfo`    | GroupInfo    | Состав — объект [GroupInfo](../Objects.md#объект-groupinfo): создатель с ролью `owner`, `version: 1` |

```json
{
  "status": 1,
  "response": {
    "conversation": {
      "conversationId": 12,
      "type": "group",
      "memberIds": null,
      "name": "Команда",
      "description": "Рабочие вопросы",
      "avatar": null,
      "opponentUserId": null,
      "lastMessage": null,
      "positionUpdatedAt": 1790846400123,
      "updatedInfoAt": 1790846400123,
      "unreadCount": 0,
      "lastReadMessageId": 0,
      "changeVersion": 57
    },
    "groupInfo": {
      "conversationId": 12,
      "version": 1,
      "members": [
        { "userId": 1, "role": "owner", "joinedAfterMessageId": 0 }
      ]
    }
  },
  "actions": [
    { "type": "users", "data": { "userIds": [1] } }
  ]
}
```

Во все соединения создателя рассылается событие [`groups` / `created`](../websocket/Groups.md#groups--created--группа-создана).

Метод не идемпотентен: повтор запроса после обрыва сети создаст ещё одну группу.

### Ошибки

| Код  | Описание |
|------|----------|
| 1003 | Невалидное `name`: пустое после обрезки или длиннее 128 символов |
| 1007 | Невалидное `description`: длиннее 1024 символов |
| 2003 | Пользователь не авторизован |
| 3003 | Файл `avatarFileId` не является изображением |
| 3004 | Файл `avatarFileId` не найден, невалидный или загружен другим пользователем |

## POST /groups/addMembers — Добавление участников

Добавляет пользователей в группу. Только владелец. Добавленные видят всю историю группы; непрочитанных у них нет — указатель прочтения ставится на последнее сообщение.

### Параметры запроса

| Поле             | Тип   | Обязательное | Описание |
|------------------|-------|--------------|----------|
| `conversationId` | Int   | Да           | Группа |
| `userIds`        | Int[] | Да           | Пользователи, от 1 до 100. Через запятую (`userIds=2,3`) или массивом (`userIds[]=2&userIds[]=3`). Повторы игнорируются |

Пользователи обрабатываются по порядку `userIds`; кого добавить нельзя, тот попадает в `notAddedUsersInfo` с причиной — это не ошибка метода.

### Успешный ответ

| Поле                | Тип             | Описание |
|---------------------|-----------------|----------|
| `addedUserIds`      | Int[]           | Добавленные, в порядке `userIds` |
| `notAddedUsersInfo` | UserErrorInfo[] | Не добавленные — объекты [UserErrorInfo](../Objects.md#объект-usererrorinfo), в порядке `userIds` |
| `groupInfo`         | GroupInfo       | Состав после изменения |

Коды в `notAddedUsersInfo`:

| Код  | Причина |
|------|---------|
| 4001 | Пользователь не найден |
| 5005 | Достигнут лимит в 100 участников: добавлены первые по порядку, остальные — с этим кодом |
| 5006 | Уже участник группы (в том числе сам владелец) |

```json
{
  "status": 1,
  "response": {
    "addedUserIds": [2, 5],
    "notAddedUsersInfo": [
      { "userId": 1, "errorCode": 5006 },
      { "userId": 999, "errorCode": 4001 }
    ],
    "groupInfo": {
      "conversationId": 12,
      "version": 2,
      "members": [
        { "userId": 1, "role": "owner", "joinedAfterMessageId": 0 },
        { "userId": 2, "role": "member", "joinedAfterMessageId": 318 },
        { "userId": 5, "role": "member", "joinedAfterMessageId": 318 }
      ]
    }
  },
  "actions": [
    { "type": "users", "data": { "userIds": [2, 5] } }
  ]
}
```

Action `users` — добавленные (остальных участников клиент владельца знает по открытой группе); если никого не добавили, не отдаётся. Клиент показывает уведомление с числом не добавленных и, по запросу, подробности по `notAddedUsersInfo`.

Если кто-то добавлен, всем участникам после изменения рассылается [`groups` / `membersAdded`](../websocket/Groups.md#groups--membersadded--участники-добавлены). Если не добавлен никто, событий нет и `groupInfo.version` не меняется.

### Ошибки

| Код  | Описание |
|------|----------|
| 1004 | `userIds` не передан, пуст, содержит больше 100 элементов или элемент, не являющийся целым неотрицательным числом |
| 2003 | Пользователь не авторизован |
| 5002 | Группа не найдена, невалидный `conversationId` или пользователь в ней не состоит |
| 5003 | Переписка не группа |
| 5004 | Текущий пользователь не владелец |

## POST /groups/removeMembers — Удаление участников

Удаляет участников из группы. Только владелец. Удалённый сразу теряет доступ к группе; его сообщения остаются и видны участникам.

### Параметры запроса

| Поле             | Тип   | Обязательное | Описание |
|------------------|-------|--------------|----------|
| `conversationId` | Int   | Да           | Группа |
| `userIds`        | Int[] | Да           | Участники, от 1 до 100 — как в `addMembers` |

### Успешный ответ

| Поле                  | Тип             | Описание |
|-----------------------|-----------------|----------|
| `removedUserIds`      | Int[]           | Удалённые, в порядке `userIds` |
| `notRemovedUsersInfo` | UserErrorInfo[] | Не удалённые — объекты [UserErrorInfo](../Objects.md#объект-usererrorinfo): `5007` — не участник (в том числе несуществующий пользователь), `5008` — сам владелец (выйти — через [`/groups/leave`](#post-groupsleave--выход-из-группы)) |
| `groupInfo`           | GroupInfo       | Состав после изменения |

```json
{
  "status": 1,
  "response": {
    "removedUserIds": [5],
    "notRemovedUsersInfo": [
      { "userId": 1, "errorCode": 5008 }
    ],
    "groupInfo": {
      "conversationId": 12,
      "version": 3,
      "members": [
        { "userId": 1, "role": "owner", "joinedAfterMessageId": 0 },
        { "userId": 2, "role": "member", "joinedAfterMessageId": 318 }
      ]
    }
  }
}
```

Если кто-то удалён, оставшимся и удалённым рассылается [`groups` / `membersRemoved`](../websocket/Groups.md#groups--membersremoved--участники-удалены).

### Ошибки

Как у [`addMembers`](#post-groupsaddmembers--добавление-участников).

## POST /groups/changeOwner — Передача владения

Передаёт владение другому участнику. Только владелец. Бывший владелец остаётся участником с ролью `member`.

### Параметры запроса

| Поле             | Тип | Обязательное | Описание |
|------------------|-----|--------------|----------|
| `conversationId` | Int | Да           | Группа |
| `newOwnerUserId` | Int | Да           | Новый владелец — участник группы |

### Успешный ответ

| Поле        | Тип       | Описание |
|-------------|-----------|----------|
| `groupInfo` | GroupInfo | Состав после изменения |

```json
{
  "status": 1,
  "response": {
    "groupInfo": {
      "conversationId": 12,
      "version": 4,
      "members": [
        { "userId": 1, "role": "member", "joinedAfterMessageId": 0 },
        { "userId": 2, "role": "owner", "joinedAfterMessageId": 318 }
      ]
    }
  }
}
```

Всем участникам рассылается [`groups` / `ownerChanged`](../websocket/Groups.md#groups--ownerchanged--владелец-сменился).

### Ошибки

| Код  | Описание |
|------|----------|
| 2003 | Пользователь не авторизован |
| 5002 | Группа не найдена, невалидный `conversationId` или пользователь в ней не состоит |
| 5003 | Переписка не группа |
| 5004 | Текущий пользователь не владелец |
| 5007 | `newOwnerUserId` не участник группы или невалидный |
| 5008 | `newOwnerUserId` — текущий владелец |

## GET /groups/getInfo — Состав группы

Возвращает состав и роли группы. Любой участник. Клиент вызывает метод при открытии экрана группы и после переподключения WebSocket, пока экран открыт (см. [правила клиента GroupInfo](../Objects.md#объект-groupinfo)).

### Параметры запроса

| Поле             | Тип | Обязательное | Описание |
|------------------|-----|--------------|----------|
| `conversationId` | Int | Да           | Группа |

### Успешный ответ

| Поле        | Тип       | Описание |
|-------------|-----------|----------|
| `groupInfo` | GroupInfo | Состав и роли — объект [GroupInfo](../Objects.md#объект-groupinfo) |

```json
{
  "status": 1,
  "response": {
    "groupInfo": {
      "conversationId": 12,
      "version": 4,
      "members": [
        { "userId": 1, "role": "member", "joinedAfterMessageId": 0 },
        { "userId": 2, "role": "owner", "joinedAfterMessageId": 318 }
      ]
    }
  },
  "actions": [
    { "type": "users", "data": { "userIds": [1, 2] } }
  ]
}
```

Action `users` — все участники.

### Ошибки

| Код  | Описание |
|------|----------|
| 2003 | Пользователь не авторизован |
| 5002 | Группа не найдена, невалидный `conversationId` или пользователь в ней не состоит |
| 5003 | Переписка не группа |

## POST /groups/leave — Выход из группы

Выход текущего пользователя из группы. Доступен любому участнику, включая владельца. Если выходит владелец, владельцем становится участник, вступивший раньше всех. Если выходит последний участник, в группе никого не остаётся и переписка становится недоступна. Предупреждения перед выходом клиент показывает по [GroupInfo](../Objects.md#объект-groupinfo).

### Параметры запроса

| Поле             | Тип | Обязательное | Описание |
|------------------|-----|--------------|----------|
| `conversationId` | Int | Да           | Группа |

### Успешный ответ

| Поле                  | Тип                 | Описание |
|-----------------------|---------------------|----------|
| `removedConversation` | RemovedConversation | Метка выхода — объект [RemovedConversation](../Objects.md#объект-removedconversation) с новой версией пользователя |
| `totalUnreadCount`    | Int                 | Общий счётчик непрочитанных после вычета непрочитанных группы, на версии `removedConversation.changeVersion`; применяется по правилам [ReadInfo](../Objects.md#объект-readinfo) |

```json
{
  "status": 1,
  "response": {
    "removedConversation": { "conversationId": 12, "changeVersion": 131 },
    "totalUnreadCount": 3
  }
}
```

Оставшимся и вышедшему (во все его соединения) рассылается [`groups` / `memberLeft`](../websocket/Groups.md#groups--memberleft--участник-вышел).

### Ошибки

| Код  | Описание |
|------|----------|
| 2003 | Пользователь не авторизован |
| 5002 | Группа не найдена, невалидный `conversationId` или пользователь в ней не состоит |
| 5003 | Переписка не группа |
