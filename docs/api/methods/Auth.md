# /auth — Регистрация, вход, выход

[← Методы API](../Methods.md) · [Документация API](../../../API_Documentation.md)

## POST /auth/signup — Регистрация

Создаёт нового пользователя и устанавливает сессию.

### Параметры запроса

| Поле       | Тип    | Обязательное | Требования                                                                                         |
|------------|--------|--------------|----------------------------------------------------------------------------------------------------|
| `login`    | String | Да           | Латинские буквы (a–z, A–Z), цифры, символ `_`; не длиннее 64 символов                             |
| `password` | String | Да           | Не менее 8 символов; минимум одна заглавная буква (A–Z), одна строчная (a–z), одна цифра (0–9)    |
| `name`     | String | Да           | Буквы (любые), цифры, дефис `-`, нижнее подчёркивание `_`, пробел; не длиннее 128 символов        |

### Успешный ответ

В `response` — объект [User](../Objects.md#объект-user) созданного пользователя.

```json
{
  "status": 1,
  "response": {
    "userId": 1,
    "login": "ivan",
    "name": "Ivan Petrov",
    "avatar": null
  }
}
```

## POST /auth/login — Авторизация

Выполняет вход для существующего пользователя и устанавливает сессию.

### Параметры запроса

| Поле       | Тип    | Обязательное | Требования                                     |
|------------|--------|--------------|------------------------------------------------|
| `login`    | String | Да           | Латинские буквы (a–z, A–Z), цифры, символ `_` |
| `password` | String | Да           | Минимум 6 символов                             |

### Успешный ответ

В `response` — объект [User](../Objects.md#объект-user) вошедшего пользователя.

```json
{
  "status": 1,
  "response": {
    "userId": 1,
    "login": "ivan",
    "name": "Ivan Petrov",
    "avatar": null
  }
}
```

---

## POST /auth/logout — Завершение сессии

Уничтожает текущую сессию и удаляет cookie. Требует активной сессии.

### Параметры запроса

Отсутствуют.

### Успешный ответ

```json
{
  "status": 1,
  "response": {}
}
```
